# LiNC branding

Source artwork for the LiNC application icon and the GitHub organization avatar.

## Files

- `linc-icon.svg` — app icon source, rounded graphite shell
- `linc-icon-16.png` … `linc-icon-512.png` — raster sizes for the desktop icon
- `linc-icon.ico` — Windows icon bundle
- `linc-org.svg` — full-bleed organization avatar source
- `linc-org-1024.png` — upload this as the GitHub organization avatar
- `linc-org-512.png` — smaller avatar copy

The app embeds `linc-icon-256.png` and sets it as the window icon at startup.

## Palette

- graphite `#141619`
- panel `#1b1e22`
- foreground `#e8eaed`
- accent `#4da3ff`
- cyan `#67e8f9`
- cutter `#fb923c`

Keep the mark clear of the outer 8% of the canvas. The organization avatar is
full-bleed because GitHub applies a circular crop.
