# Probe help figures

The UI screenshots (`boss-and-pocket.png`, `calibrate.png`, `edge-angle.png`,
`outside-corners.png`, `parameters.png`, `probing-hints.png`, `results.png`,
`work-offsets.png`) are LiNC screenshots, captured at 2560x1440 and cropped to
the relevant controls. Routine-button crops show the buttons only, with
intact borders and symmetrical margins.

The two parameter diagrams are clean SVGs based on Probe Basic:

- `step-off-width.svg`
- `extra-probe-depth.svg`

The artwork was vectorized with Inkscape and then rebuilt as clean SVG shapes;
the framed description is live SVG text, not paths, so it stays crisp and
themeable. The ruby probe-tip color is preserved.
