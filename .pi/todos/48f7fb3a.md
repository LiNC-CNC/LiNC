## Status

The live readout shipped in `93c76fa` (and the pieces it rests on in `df6069a`,
`a6c015b`, `891bd7b`, `1bc46ab`). What the original plan called "optional,
~a day" is the thing that got built; the static report did not.

Shipped:

- `linc-core::gcode` — `LoopKind`/`LoopTrace` on `Preview.loops`: opening line,
  test line, body's last line, the test's parameter keys, the subset the body
  assigns (`counters`), one value vector per pass (capped at
  `LOOP_TRACE_LIMIT` = 4096), and a `live` flag for `#5xxx`/`#<_…>` tests.
  Every segment carries the whole nest it sits in (`Preview.segment_loop`
  indexes `Preview.loop_stacks`).
- `linc-ui` — `LoopProgress` follows `motion.program_line` through the
  execution-ordered plan; `LoopReadout::line()` renders
  `#<level>=0 1/3 | #<row>=0 1/12 | #<col>=0 1/72`, outermost first, in the
  PROGRAM footer and the MAIN toolpath status line.

## Not built

- **Static loop report.** A table of every loop with its iteration count and the
  values the preview computed, for reviewing a program before it runs. The
  running readout answers "where am I"; this would answer "what will it do".
- **Subroutine listing follow.** If LinuxCNC ever publishes the interpreter's
  filename, the same follower lets the listing open the subroutine's text
  instead of only naming it.

## Known limits (deliberate, documented in code)

- Only counters are shown: a test parameter the body assigns. Limits
  (`#<levels>`) are left out.
- `≈` marks a loop whose test reads machine state; those values are the
  preview's model. The preview cannot know `#5070`, reads it as 0, so such a
  test never turns false and the trace runs to its 4096 cap.
- A loop that repeats one motion line at identical coordinates cannot be told
  apart by position, so the pass may stay on an earlier one.
- On a 1280 px Program page a three-deep nest is elided after the second
  counter; the full line is on hover. The MAIN card is wide enough for all
  three.
- `PREVIEW_STEP_LIMIT` stays 200 000; raising it bought nothing on break-less
  or live-state loops.
